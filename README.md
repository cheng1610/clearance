# clearance
clearance is a Discord bot developed using **Pycord**, powerful and easy-to-use cleanup bot for Discord servers

## Inatall
### Python 3.8 or higher is required
```cmd
git clone https://github.com/cheng1610/clearance.git
cd clearance
```
## Commands
- clear_message
- clear_channel
- clear_category
- clear_role
- clear_user_message
- autoclear
